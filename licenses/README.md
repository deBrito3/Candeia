# Third-party components / Componentes de terceiros

Candeia does not redistribute any third-party component yet. When a component starts shipping with the game, its license texts go in this directory and a row goes in the table below.

| Component | Version | Source | License files | Ships from |
| --- | --- | --- | --- | --- |

| .NET runtime and Windows Desktop runtime (self-contained publish) | to be pinned | https://dotnet.microsoft.com/ | to be added | Delivery 10 |

The game uses Windows-provided fonts; font files are not redistributed. Artwork and sounds are drawn and synthesized by the game's own code.
