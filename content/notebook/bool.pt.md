# bool: sim ou não

`bool` guarda só duas respostas: `true` (verdadeiro, sim) ou `false` (falso, não). É o tipo das perguntas da casa: a lâmpada começa acesa? A porta está trancada?

```csharp
bool acesa = true;
bool trancada = false;
```

Sem aspas: `"true"` entre aspas é um texto, não um `bool`.

As comparações também dão um `bool`: `watts > 40` vale `true` quando a lâmpada passa de 40 watts. Mais adiante, o `if` usa essas respostas para decidir o que fazer.
