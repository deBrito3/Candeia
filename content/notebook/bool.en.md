# bool: yes or no

`bool` keeps only two answers: `true` (yes) or `false` (no). It is the type of the house's questions: does the lamp start lit? Is the door locked?

```csharp
bool lit = true;
bool locked = false;
```

No quotes: `"true"` in quotes is a text, not a `bool`.

Comparisons give a `bool` too: `watts > 40` is `true` when the lamp uses more than 40 watts. Later on, `if` uses these answers to decide what to do.
