# int: whole numbers

`int` keeps whole numbers, with no decimals: `0`, `60`, `-5`, `2024`.

```csharp
int watts = 60;
int floors = 2;
```

An `int` goes up to a little over 2 billion. For bigger numbers there is `long`, which works the same way.

Careful: if you divide one `int` by another, the result is a whole number too, and the decimals vanish. See the page on division.
