# int: números inteiros

`int` guarda números inteiros, sem casas decimais: `0`, `60`, `-5`, `2024`.

```csharp
int watts = 60;
int andares = 2;
```

Um `int` vai até pouco mais de 2 bilhões. Para números maiores, existe o `long`, que funciona igual.

Cuidado: se você dividir um `int` por outro, o resultado também é inteiro, e as casas decimais somem. Veja a página da divisão.
