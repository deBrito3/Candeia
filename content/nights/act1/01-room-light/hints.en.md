## 1

Each method only needs to give back one value. That value's type must match the type written before the method's name: `double`, `bool` or `string`.

## 2

You declare a variable like this: the type, the name, `=` and the value, as in `int watts = 60;`. A `double` can have a decimal point, like `220.0`. A `bool` is only `true` or `false`. A `string` goes in double quotes, like `"CND-60"`.

## 3

Fill in the blanks:

```csharp
double volts = ___;
return volts;

bool on = ___;
return on;

string model = ___;
return model;
```
