# From zero: how to read this night

Never programmed? Start here. In Vigil, this part comes before the first night's README.

- **The code** is the text in the middle of the screen. The computer reads it from top to bottom.
- **A class**, such as `public static class RoomLight`, is a box that gathers the questions about one thing: here, the bedroom lamp. Everything that belongs to it sits between the braces `{` and `}`.
- **A method** is a question the house asks. `public static int Watts()` means: the question `Watts`, which answers with a whole number (`int`). What sits between the method's braces is the answer, and that is what you write.
- **`return`** hands the answer over. When the method reaches the `return`, the house gets the value, and the method ends right there.
- **Each command** ends with a semicolon: `;`.
- **F5** runs the code. The house asks its questions, and each right answer lights a lamp up top.
- **The OUTPUT tab** (Ctrl+2) explains what went wrong. A writing error shows its line and what was missing. A lamp that did not light shows what the house expected and what your code answered.
- **F1** on a word of the code opens its page in the notebook, for free.

In Vigil you get more time, four candles, and the hints are free. Nobody learns in a hurry.
