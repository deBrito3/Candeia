## 1

Cada método só precisa devolver um valor. O tipo desse valor precisa bater com o tipo escrito antes do nome do método: `double`, `bool` ou `string`.

## 2

Uma variável se declara assim: o tipo, o nome, `=` e o valor, como em `int watts = 60;`. Um `double` pode ter ponto decimal, como `220.0`. Um `bool` só vale `true` ou `false`. Um `string` vai entre aspas duplas, como `"CND-60"`.

## 3

Complete as lacunas:

```csharp
double volts = ___;
return volts;

bool on = ___;
return on;

string model = ___;
return model;
```
